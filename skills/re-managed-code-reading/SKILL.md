# JVM 与 .NET 托管代码阅读

1. 记录产物类型与运行时、依赖或符号版本。以用户提供的类表、程序集清单、中间语言或反编译文本为输入，围绕一个明确的问题选择入口。
2. 先按包、命名空间或程序集划分模块，再追踪入口到关键调用。记录类型、方法签名、传递的数据和必要的返回值。出现异步状态机时，按等待点和恢复点整理流程。
3. 对反射、动态加载、虚调用和框架回调只给出证据支持的候选路径。对照元数据和可见调用点核验反编译器重构的控制流，保留无法还原的名称或类型。
4. 输出简短的调用路径、模块职责和证据位置。用类型及方法签名标注关键步骤，不加载程序集、不执行初始化器、不修改产物。
