# 离线协议消息格式分析

1. 收集用户已导出并脱敏的消息样本、方向、长度、记录时间及已知场景。每条样本保留独立编号。无需接触设备或在线服务。
2. 比较相同场景内的稳定字节和变化字节，再对照不同长度或场景的样本。为候选字段记录偏移、宽度、端序和样本证据。长度字段需注明其覆盖范围和计数单位。
3. 用已提供的独立样本验证每个假设，并保留反例。注明抓包截断、分片、重组或缺乏解码资料给结论带来的限制。未知字段保持未知。
4. 交付字段表、样本编号和可靠性说明。使用脱敏示例描述格式，保持分析被动，不生成探测、重放或注入流量。
