# 固件布局与组件识别

1. 记录用户给出的镜像来源、设备型号和版本。选择明确提供的镜像头摘要、分区表、已提取的目录清单或构建文件作为证据。
2. 依据已知分区表整理名称、偏移、大小和用途。以实际镜像大小为边界核对区间，报告重叠和不合理数值，同时考虑容器层与子分区可能使用不同的偏移基准。
3. 使用已有文件清单识别启动组件、系统镜像、配置目录和第三方组件。分别标记文件名提示、包元数据和明确配置引用，避免把文件存在当作运行证据。
4. 给出分区表、组件表和已证实的启动关系。遇到加密层、未知容器或未提供的子目录时标为未知。保持镜像原样，不执行、挂载、刷写或自动解包。
