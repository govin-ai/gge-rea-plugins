# 原生二进制静态阅读

1. 确认样本、架构和用户想理解的功能。优先使用用户提供的反汇编、反编译、符号或映射表。只有宿主已具备静态查看能力时，才读取指定二进制的必要元数据。文件头标识、虚拟地址和文件偏移应分别记录。
2. 从与问题有关的入口、导入、导出或字符串引用出发，沿直接调用和数据引用缩小范围。记录支撑结论的调用点、参数、返回值和数据流。遇到间接调用或反编译器无法确定的类型，保留候选和缺失证据。
3. 按已观察到的行为给临时符号起名，并保留原始地址或符号以便复查。用至少一个调用点或实际字节证据校验关键推断。仅根据导入函数名或单个字符串无法确认某个运行时行为。
4. 交付模块图或简短函数表，列出地址、行为、证据和待核实项。仅进行静态阅读，不执行或改写样本，不推导利用链或绕过方式。
